| **ADR-03: Fallback Silencioso** | `voice_router.py` | **High Availability / Fallback Chain / Graceful Degradation** | Falhas temporárias de provedores em nuvem não interrompem a produção. A esteira comuta automaticamente para o motor local neural Kokoro-82M. |
| **ADR-04: Quarentena Atômica** | `data/quarantine/` | **Dead Letter Queue (DLQ) / Defect Isolation Pattern** | Artefatos gerados que falham no controle de qualidade visual ou sonoro são isolados com relatório de diagnóstico sem contaminar o release final. |
| **ADR-05: Prompts Dual-Shot Nolan** | `darkfactory_t2v.py` | **Domain Archetype Enforcement / Cinematic Consistency** | Mitiga alucinações e tomadas genéricas de modelos generativos exigindo sempre a dobradinha Shot A (drama) + Shot B (macro) com especificações de película Kodak. |
| **ADR-06: Git Main Hard Gate** | Hook `stop_gate.py` | **Deployment Guardrail / Branch Hygiene / Zero Lost Work** | Bloqueia a finalização da sessão de desenvolvimento enquanto houver arquivos modificados ou pendentes de commit e push na branch `main`. |
